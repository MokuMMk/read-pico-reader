# Pico 阅读固件

[English](README.md) · [日本語](README.ja-JP.md) · [第三方许可](THIRD_PARTY_NOTICES.md)

这是为 **MindReset Read Pico（RDP-G01-W）** 墨水屏开发板制作的独立开源阅读固件，基于 [MindReset 官方示例固件](https://github.com/MindReset/read_pico_firmware) 开发，**并非 MindReset 官方发布**。

界面包括首页、书架、文件管理和设置；可阅读 TF 卡中的 EPUB、TXT，保存阅读进度，并通过 WiFi、设备热点或 USB 传输文件。

## 在线网页刷机

打开 [HTTPS 在线刷机页](https://wegooo-cell.github.io/read-pico-reader/)。在电脑端 Chrome 或 Edge 中，用支持数据传输的 USB 线连接 **Read Pico RDP-G01-W**，选择设备串口并按提示刷入。**刷机前确认型号。**普通刷机保留设备设置、阅读记录和 TF 卡内容；固件不附带书籍或预设的阅读记录。

如果运行本固件的设备无法自动进入下载模式，可在设备上点击**文件管理 → BOOT**，等电脑重新识别串口后再用网页刷机。

刷机页现有图文新手指南：**连接 Pico → 选择串口 → 确认安装并等待完成**。页面下方也介绍了首页、书架、文件管理和设置，以及常见问题。

刷机清单为 [`flash/manifest.json`](flash/manifest.json)，写入引导程序、分区表、应用程序和 OTA 数据分区；不会覆盖现有 NVS 设置与内置书籍分区。网页由 [Pages 工作流](.github/workflows/pages.yml) 按明确的文件清单部署，不上传本机书籍、备份或额外字体包。[查看本次详细更新日志](docs/RELEASE_NOTES_0.3.3-rc69.md)。

## TF 卡本地升级

启用本地升级时，需要先用电脑完整刷入一次带双分区的 OTA 基础版；这一步会更新引导程序和分区表，但保留原来的设备设置、阅读记录、内部存储地址与 TF 卡内容。之后把对应设备型号的应用镜像命名为 `Pico-update.bin`，放到 TF 卡根目录，进入**文件管理 → 升级 → 安装升级**。

设备会先检查固件项目名、版本、文件大小和镜像头，再把升级包写入当前未使用的固件槽。完整性校验通过后才切换启动槽；新版本首次启动如果未通过硬件与界面检查便异常复位，引导程序会自动回到上一槽。安装过程中请保持供电，不要取出 TF 卡。TF 卡升级包只包含应用程序，不能代替首次安装 OTA 基础版，也不能用于更换分区表或引导程序。

## 自行编译

需要 ESP-IDF **v6.1**，目标芯片为 ESP32-S3：

```sh
idf.py set-target esp32s3
idf.py build
```

`sdkconfig.defaults` 使用本开发板对应的 Flash/PSRAM 时序；`sdkconfig.ci` 仅用于编译检查。硬件资料请看 [MindReset 官方文档](https://dot.mindreset.tech/docs/read_0)。预编译固件仅面向 RDP-G01-W。

## 书籍与字体

首次挂载 TF 卡时，固件会按需建立 `books`、`fonts`、`pictures` 文件夹，不会预装书籍。系统界面内建 **思源黑体 Medium 子集**，除此之外不提供字体包。用户可自行把兼容字体放入 TF 卡的 `fonts` 文件夹，供阅读正文选择。内建字体遵循 [SIL OFL 1.1](main/assets/OFL-Noto.txt)。

书架中的「封面与书脊」模式标为**测试版、非正式版本**；其他书架样式照常使用。

TXT 或没有有效内嵌封面的 EPUB 会按书籍路径稳定生成灰阶封面；书架、首页和阅读票根显示同一版式。有效的 EPUB 原封面仍优先使用。生成结果缓存在 TF 卡的 `.readpico/covers` 中，文件或书名变化后会重新生成。

首次开机没有插 TF 卡时，之后插卡会自动探测并更新首页、书架与文件管理。已挂载的卡请勿在阅读或传输时直接拔出；若已拔出，请插好卡后重启设备，以免旧文件句柄误写。

阅读时轻点正文中央可切换全屏，按屏幕下方中间触控键打开阅读设置。全屏底部有一条细的全书进度线，正文会利用更多底部空间。字体设置主面板可调整字号、选择阅读字体、切换晃动翻页与阅读线；点开「排版设置」可调整边距、行距、段距、字间距和首行缩进。字间距默认位于滑轨中间；首行缩进可选无、1 字、2 字或 3 字，默认 2 字。正文会把可容纳的整列文字居中，避免右侧留白明显宽于左侧；常见中文句末标点不会单独排到下一行开头，左括号和左引号不会留在行尾。点按「阅读线」卡片依次切换无、虚线和点线；选中线型后，可用卡片里的「上移」「下移」每次微调 2 像素。阅读设置中的「刷新设置」可选择每 5、10、15、30 页全刷，或选「不强制」关闭定期全刷；手动全刷始终可用。在「设置 → 阅读操作」中可开启电源键翻页（阅读正文短按下一页、长按锁屏）及全屏沉浸（全屏时隐藏状态栏）。这两个开关默认关闭。

需要备份个性化设置时，进入**设置 → 保存与恢复 → 保存当前配置到 TF 卡**，文件保存在卡根目录的 `Pico-settings.backup`。再次刷机或换设备后，把该文件放回 TF 卡根目录，在同一页面选择**从 TF 卡恢复配置**并再次确认。备份包含系统与阅读字体、字号、排版、显示、锁屏、设备名称、头像路径、状态栏签名、已保存的 WiFi 名称与密码，以及每本书的阅读进度、阅读时长、书签、收藏和自定义书名。书籍、字体、头像和壁纸图片仍留在 TF 卡，不会复制进备份。备份文件含明文 WiFi 密码，请妥善保管 TF 卡；外部图片或字体已不存在时，会回退到默认显示。旧版备份仍可恢复，但不会改动当前的网络配置。

大型 EPUB 的章节、目录和清单按实际数量分配内存；ZIP 条目与章节分别有 8,192 项上限，书籍还需为封面、图片和目录留出条目。整本文件可以大于 32 MB，但单个正文文件仍限定为 4 MB、单张解压图片限定为 8 MB，且受设备剩余内存与普通 ZIP 格式限制。
