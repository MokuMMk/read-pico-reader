BEFORE YOU START

先准备这 3 样

1确认设备型号

这份固件只给 MindReset Read Pico RDP-G01-W 使用。

2打开电脑浏览器

在电脑上使用 Chrome 或 Edge 打开本页。

3准备数据线

使用能传文件的 USB-C 线；仅能充电的线无法刷机。

继续读上次打开的书，查看近 7 天阅读时长。

02 / LIBRARY书架

找到已导入的书，点封面开始阅读。

03 / FILES文件管理

通过 WiFi、热点或 USB 传输导入书籍和文件。

04 / SETTINGS设置

调整系统字体、书架样式和锁屏等选项。

第一次插入 TF 卡后，系统会建立 books、fonts、pictures 文件夹。EPUB / TXT 书籍放进 books；TTF 字体放进 fonts；图片放进 pictures。固件只内建思源黑体 Medium 子集，不附带其他字体包。

HELP

遇到问题时

点了按钮，却看不到 Pico 的串口？

先确认你在电脑端 Chrome 或 Edge 中打开了本站，并退出 Pico 的 USB 读卡模式。换一根确定能传文件的 USB 线，拔插设备后重试；若串口被其他刷机工具占用，先关闭那个工具。已安装新版固件的设备也可从“设置 → 升级和恢复 → BOOT 刷机”进入刷写模式。

为什么需要进入 BOOT 模式？

正常连接 USB 串口时，刷机工具会尝试自动切换。若设备处于锁屏休眠或电脑未识别到串口，可先唤醒 Pico，再从设置中的“BOOT 刷机”进入 BOOT 模式，等电脑重新识别后重试。首次刷机时若还没有这个菜单，可先尝试直接连接刷机。

刷完开机，为什么书架是空的？

固件不预装书。请插入 TF 卡，在“文件管理”中使用 WiFi、热点或 USB 传书，也可以把 EPUB / TXT 文件放进 TF 卡的 books 文件夹。

阅读时怎样打开设置？

阅读正文默认单击中键打开阅读工具栏，长按中键全刷，中间双击切换全屏。可在“阅读设置 → 按键控制”自定义三键或选择两套推荐配置。
