# Pico Reader

[English](README.md) · [简体中文](README.zh-CN.md) · [Third-party notices](THIRD_PARTY_NOTICES.md)

MindReset Read Pico（RDP-G01-W）向けの独立したオープンソース読書ファームウェアです。[MindReset の公式デモ](https://github.com/MindReset/read_pico_firmware)を基にしていますが、**MindReset の公式リリースではありません**。

EPUB と TXT の読書、読書位置の保存、TF カードのファイル管理、Wi-Fi・ホットスポット・USB での転送に対応します。[HTTPS オンライン書き込みページ](https://wegooo-cell.github.io/read-pico-reader/)は PC 版 Chrome または Edge と USB データケーブルで利用できます。書き込む前に基板型番を確認してください。通常の書き込みでは設定、読書記録、TF カードの内容を消去しません。

オンライン書き込みではブートローダー、パーティションテーブル、アプリ、OTA データ領域を書き込みます。既存の NVS 設定と内部の書籍領域は維持されます。書棚の「表紙と背表紙」モードは**テスト版（正式版ではありません）**として表示します。[更新履歴](docs/CHANGELOG.md)も参照してください。

このファームウェアを使用中で自動的にダウンロードモードへ切り替わらない場合は、本体の「设置 → 升级和恢复 → BOOT 刷机 → 进入 BOOT 模式」を選び、PC がシリアルポートを再認識してから書き込みページで再試行してください。

Wi-Fi 接続後、本体の「设置 → 升级和恢复 → 系统升级 → 检查更新」でオンライン更新を確認できます。rc84 以降は、新版の短い更新履歴と「稍后 / 开始更新」ボタンを表示します。旧版から rc84 に更新する場合は、書き込みページで今回の更新履歴をご覧ください。

TF カード内の任意のフォルダーから TXT/EPUB を開いて読書位置を保存すると、再スキャンせずに書棚へ追加されます。書棚管理の「移出书架」は項目を非表示にするだけで、ファイル・読書位置・お気に入りは残します。再び読むと書棚へ戻ります。非表示の状態は本体に保存し、設定のバックアップと復元にも含めます。

EPUB の本文の各章は新しいページから始まり、収まる場合は章題と冒頭の本文を同じページに表示します。一つの XHTML 内の複数の章も対象です。目次リンク、紹介文、著者・著作権情報は本文の章として扱わず、通常の小見出しは続けて表示します。章の検出には目次、番号付きの独立した章題と本文構造を使うため、適切なマークアップのない書籍は個別の互換性対応が必要になる場合があります。

振ってページ送りは標準では無効です。読書の字体設定で有効にすると、左方向の動作で前ページ、右方向で次ページへ進みます。ゆっくりした傾き、上下方向、タッチ中と反動は除外し、動作後は 800 ミリ秒の待ち時間と静止が必要です。実機で方向と感度を確認してください。全体の高速更新テスト項目は削除し、古い設定からも有効化しません。

## 現行リリース：rc88

起動復旧と表紙キャッシュのメモリ使用を改善し、深いスリープ後に読書を復元します。中キー長押しを設定でき、ツール入口を保護します。読書票はシステム字体、ホーム・読書タイトルは各画面の字体を本来のサイズで描画します。USB・TF・OTA は同じビルドを使い、本体にも短い更新履歴を表示します。rc87 は公開を取り下げ、元の rc85/rc86 は引き続き選択できます。

## 入力方式

九宮格は中国語ピンイン専用で、英語と大文字・小文字の切り替えは全キーボードで使用します。数字は「123」画面から入力します。削除キーを約半秒押し続けると、未確定のピンイン、カーソル前の文字の順に連続削除します。指を離すかキーの外へ動かすと停止し、通常の入力と削除は変更範囲だけ更新します。候補欄が6回変化した後、指を離して約700ミリ秒停止すると、その欄だけを一度グレースケール更新して残像を抑えます。連続入力や削除キーの長押し中は延期し、キーボードの切り替えや画面終了で取り消します。キーを押すと濃くなり少し沈み、離すと元に戻ります。487 個のオフライン単語候補、同音字の継続ページ送り、九宮格の「更多」による読み選択に対応します。内蔵黒体は GB2312 の漢字 6763 字をカバーし、TF カードのフォントは不要です。WiFi パスワードは英語全キーボード・数字・記号を使用します。これらの機能は rc86 リリースに含まれています。

ローカル修正ではオンライン更新前に未表示の表紙キャッシュを解放し、メモリ不足を安全に通知します。画面走査とファームウェアの逐次消去・書き込みを直列化します。進捗は5秒以上経過し5ポイント以上増えた時に、新しい黒い区間と百分率だけを局所更新します。完了済み区間の消去や定期的な画面全消去は行いません。終了・ロック・取消ではタスク終了を待ち、検証失敗時は現在の起動領域を維持します。

## TF カードからのローカル更新

最初に一度だけ、PC から OTA 基本版を完全に書き込み、ブートローダーと二つのファームウェア領域を導入します。既存の設定、読書記録、内部ストレージの位置、TF カードの内容は維持されます。その後はアプリケーション画像を `Pico-update.bin` という名前で TF カード直下に置き、「ファイル → 更新 → 更新をインストール」から更新できます。

本体は画像のプロジェクト名、バージョン、サイズとヘッダーを確認し、未使用側の領域だけに書き込みます。完全性の確認後に起動先を切り替え、新しい版が初回起動確認前に異常終了した場合は以前の版へ自動的に戻ります。更新中は電源と TF カードを外さないでください。アプリケーションだけの更新では、最初の OTA 基本版導入やパーティション表の変更はできません。

ビルドには ESP-IDF v6.1 が必要です。ファームウェアには Noto Sans SC Medium のサブセットのみを内蔵し、追加のフォントや書籍は配布しません。

本体の上流コードは Apache-2.0、UI アイコンは Lucide（ISC）、epdiy は LGPL-3.0-or-later、内蔵フォントは SIL OFL 1.1 に従います。適用範囲は [第三者ライセンス一覧](THIRD_PARTY_NOTICES.md)をご覧ください。

### ファイル転送

ファイル管理には WiFi 転送・ホットスポット転送・USB 転送を直接表示します。WiFi は保存済みネットワークに接続し、未設定なら接続設定へ進みます。ホットスポットは本体のアクセスポイントを開始します。USB は PC から TF カードを読み書きできます。

### メイン画面の更新と読書キー

ソース版のメイン画面の波紋は16帯を1ステップに1帯ずつ開始し、83ステップから52ステップへ短縮します。12msの目標間隔と各画素の全37位相を維持し、ソフトウェア上の目標は約996msから624msになります。実際の画面切替には描画と走査時間も含まれます。帯は少し広くなりますが、グレー波形・固定ナビゲーション・失敗復旧は維持し、読書のページ送りには影響しません。この最適化は公開済みrc89には含まれておらず、階調と残像は実機確認が必要です。

設定の表示から通常・高速・波紋を選択できます。通常と波紋はグレーを保持し、高速は白黒表紙と細かい市松模様を使います。下部ナビゲーションを保持し、選択マークのみ局所更新します。上端から下へスワイプすると WiFi・Bluetooth・全更新・ロックが開きます。読書キーは個別設定と2つの推奨設定に対応し、中央長押しは標準で全更新ですが、ホームへ戻る等の操作にも変更できます。3キーの短押しと中央長押しのうち、少なくとも一つはツールバーを開く操作にします。旧設定や復元時に入口がない場合は中央短押しを補正します。中央ダブルタップは常に全画面切替です。新しく開く本は全画面となり、ページ送りではツールバーを閉じて全画面へ戻ります。設定は再起動とバックアップ復元で保持されます。

本版では、ロック前に本・読書位置・全画面状態を保存し、深いスリープからの復元は一度だけ試行します。本の読み込みが電源断や異常再起動で中断した場合、本名とホーム・確認付き削除を表示して自動再試行を止めます。読書票はどの画面からもシステム字体で描画し、浅いスリープ解除後は元の読書字体へ戻します。クイック操作は3モードともグレーと明瞭な枠線を使います。高速モードは白黒表紙のみ、通常・波紋はグレー表紙のみ保持し、変更時に旧形式を解放します。ホームの続読書名はシステム字体を40pxで、読書画面の書名・章題は読書字体を32/48pxで直接生成します。現在の字体を再利用し、内蔵字体の追加やシステム・読書字体の同時読み込みは行いません。字体が利用できない場合は安全な内蔵補完を維持します。これらの変更は rc88 に含まれます。

オンライン書き込みの接続ボタン上で最新版または正式公開時の **rc86 / rc85** を選択できます。公開日時と TF 更新ファイルは選択した版に対応し、すべての版でデータ保持が標準です。
